# Ready prompts

*Copy one, change the bracketed bits, paste it after the brief files.*

Each says which files to paste with it. Getting that wrong is the usual reason
an output comes back thin.

---

## 1 · A two-page brochure

> **Paste first:** `01-what-vyuha-is.md`, `04-how-vyuha-talks.md`

```
Write a two-page brochure for Vyuha, aimed at a distributor doing ₹2–20 crore
a year who keeps his books in Excel.

Page 1: the problem in his words, then what Vyuha does about it.
Page 2: what he gets in the first week, and how to start.

Follow the voice rules exactly — no banned words. Lead with concrete things he
would recognise from his own shop. Under 600 words total.

Give it to me as a single self-contained HTML file, print-ready on A4, that I
can open and save as PDF. Inline CSS only, no external fonts or images.
```

## 2 · An investor deck

> **Paste first:** `01-what-vyuha-is.md`, `02-the-numbers.md`, `03-who-youre-reading-to.md`, `06-what-is-not-built.md`

```
Write a 10-slide investor deck for Vyuha (seed stage, India).

Cover the problem, why now, what we built, a worked example with the real demo
figures, the wedge and how it expands, what is not built yet, and the ask.

Use only figures from the numbers file. Where I have no data — market size,
traction, revenue — write the slide with a placeholder saying exactly what I
need to supply, rather than estimating it.

One idea per slide. The number is the sentence.

Give it as a self-contained 16:9 HTML deck: arrow-key navigation, one slide per
printed page so I can save it as PDF. Inline CSS, no external anything.
```

## 3 · A one-page leave-behind

> **Paste first:** `01-what-vyuha-is.md`, `02-the-numbers.md`, `04-how-vyuha-talks.md`

```
Write a one-page leave-behind I can hand a distributor after a meeting.

Top third: what it does, in one sentence and three bullets.
Middle: the six things Vyuha found in the worked example that the owner did not
know — use the real figures.
Bottom: what happens if he sends a file, and how to reach me.

A4, print-ready, self-contained HTML. Under 300 words. It should survive being
folded into a shirt pocket.
```

## 5 · A bank / credit file for a client

> **Paste first:** `01-what-vyuha-is.md`, `02-the-numbers.md`, `03-who-youre-reading-to.md`

```
Prepare a credit file on Shree Agro & Hardware for a lender.

Include: trading summary, cash flow, position, the ratio table with a plain
reading of each, receivables ageing, and customer concentration as a stated risk.

Lead on the negative cash conversion cycle.

State plainly, near the top, that the balance sheet is partial — no opening
balances, no fixed assets, no loans — and that figures come from trading records.

Formal tone. Self-contained HTML, A4, print-ready.
```

## 7 · A demo script

> **Paste first:** `01-what-vyuha-is.md`, `02-the-numbers.md`, `06-what-is-not-built.md`

```
Write me an 8-minute demo script for Vyuha.

For each beat: what I click, what I say, and the one number I point at. Mark
where I pause for a reaction.

Open on reading a messy file — that is the strongest moment. Close on the six
things it found that the owner did not know.

Include a short honest answer for "what doesn't it do yet".
```

## 8 · Answering a hard question

> **Paste first:** `01-what-vyuha-is.md`, `06-what-is-not-built.md`

```
A prospect asked: "[THEIR QUESTION]".

Give me a straight answer in under 80 words, and say which parts of it are
already built and which are not. Do not sell. If the honest answer is "not yet",
say that and say what I can do instead.
```

## If the output comes back wrong

| Problem | Cause |
|---|---|
| Generic, could be any software | `04-how-vyuha-talks.md` not pasted |
| Made-up figures | `02-the-numbers.md` not pasted |
| Promises things we don't have | `06-what-is-not-built.md` not pasted |
| Right facts, wrong pitch | `03-who-youre-reading-to.md` not pasted |
| Won't open properly / broken layout | Ask again for **self-contained HTML, inline CSS, no external fonts or images** |
